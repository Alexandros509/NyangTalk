# 03. 컴포넌트 명세

코드: NyangTalk `src/App/Controls/`. 상태 이름: 기본 / 올림(hover) / 누름 / 꺼짐 / 키보드 포커스.

## 체크박스·라디오 (`ThemedCheck`)
- 16px 상자(모서리 3px, 라디오는 원), 글자와 8px 간격. 글자는 **줄을 바꾸며** 높이가 늘어난다.
- 기본: input 바탕 + subText 선. 올림: 선이 accent. 켜짐: accent로 채우고 accentText 체크(라디오는 안쪽 점). 꺼짐: 선·글자를 바탕 쪽으로 흐리게.
- Space로 바꾼다. 바꾸기 전에 확인(예: 자동 기능 동의)을 거칠 수 있다.

## 값 고르기 (`ThemedChoice`) — 값이 3개 이상일 때만
- 높이 28px, 모서리 4px, 폭은 내용에 맞게 150~220px. 오른쪽 ▾.
- 누르면 테마 색 메뉴가 열리고 지금 값에 체크. ↑↓로 바로 바꾸고, Space·Enter·F4·Alt+↓로 연다.
- 고를 수 없는 값(예: "직접 조절")은 목록에 없고, 그 상태일 때 글자로만 보인다.

## 슬라이더 (`ThemedSlider`)
- 높이 28px, 4px 막대, 16px 손잡이(input 바탕 + accent 2px 테두리). 오른쪽에 숫자 값.
- 끄는 동안 바로 미리 보이고(예: 창 투명도), **놓을 때 저장**. ←→↑↓ Home End.

## 숫자 (`ThemedStepper`)
- 132×28, 양쪽에 −/+ (각 30px), 가운데 값. ↑↓, 휠(포커스가 있을 때).

## 분류 목록 (`CategoryList`)
- 항목 높이 38px, 좌우 6px 여백, 모서리 6px.
- 선택: accent 바탕 + accentText **굵은 글씨**. 올림: hover 색. ↑↓로 이동.

## 스크롤 막대 (`ThemedScrollBar`, 쪽 넘김은 `ScrollArea`)
- 폭 12px(목록)·10px(설정 쪽), 바탕 window→panel 60%, 손잡이 모서리 4px, 최소 높이 24px.
- 휠, 손잡이 끌기, 빈 곳 클릭(한 쪽), 목록의 Page Up/Down. 다크 모드에서 어두운 바탕·옅은 손잡이.

## 목록 (`ThemedList`) — 보관한 대화, 참여자, 검색 결과
- 한 줄 항목(글자 높이 + 10px), 넘치면 "…". 선택: accent 바탕. 올림: hover.
- ↑↓ Page Up/Down Home End로 선택, Enter·Delete는 소유자 동작.

## 아이콘 버튼 (`IconButton`)
- 32×30, 아이콘은 코드로 그린 선(파일 없음): 검색, 설정, 보관한 대화(말풍선 둘), 다시 연결, 더 보기(점 셋), 닫기, 위/아래, 접기/펼치기, 보내기.
- 마우스로 누른 뒤 테두리 없음. 키보드 포커스일 때만 옅은 둥근 테두리(아이콘색 60%).
- 툴팁 = 이름 + 단축키. 화면 읽기 이름도 같은 문구.

## 참여자 알약 버튼 (`FaceStack`) [결정: 시안 A]
- 높이 28px 둥근 버튼, 왼쪽 얼굴 최대 3개(22px, 14px씩 겹침), "n명"(굵게), ▾.
- 아바타·인원·▾ 구성은 유지한다. 바탕·선은 otherBubble / border, 반경 8px이며 글자·높이는 다른 필 버튼과 함께 본문 설정에 따라 커진다. 올림은 전체 80%, 비활성 40% 불투명도이며 누름은 올림과 같은 색을 쓴다. Enter·Space로 연다.

## 참여자 사이드 패널 (`ParticipantsPanel`) [결정]
- 너비 240px, panel 바탕, 왼쪽 1px border 선. 위에 "참여자 n명"(굵게)과 닫기, 아래에 안내 한 줄.
- 창 폭 560 이상: 오른쪽에 붙음(대화가 그만큼 좁아짐). 그보다 좁으면 대화 위에 겹침, 바깥 클릭·Esc로 닫힘.

## 게임 연결 버튼 [결정]
- 상태 줄 끝, 상태 줄 크기 글자, accent 1px 테두리. 연결되면 숨김. 헤더가 너무 좁으면 "더 보기(…)"로.

## 이름 첫 글자 원
- 그림이 없을 때 이름 첫 글자를 흰 글자로. 사람별 색을 흰 글자와 4.5:1이 되게 조정한 원.
- 글자는 **보이는 모양의 가운데**에 둔다(글꼴 줄 상자 기준이면 한글 글꼴에서 어긋남). [결정]

## 상태 점 (`StatusDot`)
- 11px 점 + 한 줄 문장. 연결됨 `#1F9D55`, 기다림 `#C98A00`, 꺼짐 subText.

## 버튼(글자)
- Flat, panel 바탕, border 1px 테두리, 올림 hover, 누름 pressed. 위험 버튼은 글자·테두리 warning.

## 설정 쪽 레이아웃 (`SettingsPage`)
- 블록을 위에서 아래로: 소제목 / 항목 줄 / 안내 글 / 강조 띠 / 버튼 줄(넘치면 다음 줄) / 미리보기.
- 항목 줄: 라벨(줄바꿈) + 컨트롤, 아래에 안내·상태·꺼진 이유 한 줄.

## 글자 필 버튼 (`HeaderPill`)

아이콘/필 선택과 명령 위치는 유지한다. 헤더 버튼은 WinForms의 직접 그리기로 렌더링한다. 반경·패딩·간격·상태는 `02-tokens.md`의 승인 값과 같다. 바탕·선·글자를 배경에 합성한 색으로 화면에 직접 그려 중간 비트맵 확대를 피한다. 본문 크기에 따라 글자·버튼 높이·폭이 함께 커지고, 좁은 창에서는 기존 더 보기 동작을 유지한다.

## 상단 알림과 내 메시지

- 연결 알림은 soft 바탕과 text 글자로 표시한다. 동작 버튼은 panel / midText / border의 필 스타일이며 닫기와 안내 글을 가리지 않도록 좁은 창에서는 다음 줄로 이동한다.
- 기본 본문은 11pt다. 본문 변경 시 헤더 버튼, 입력 영역 높이와 보내기 폭을 다시 계산한다. 입력창 아래 보조 문구는 별도 보조 크기와 줄 높이를 쓴다.
- 입력 영역 바탕은 panel, 입력칸은 otherBubble / text다. 비활성 보내기는 panel 위에 accent / accentText를 40%로 합성해 기준 스타일의 꺼짐 상태를 따른다.
- 내 메시지의 시간은 말풍선 왼쪽 아래에, 내 아바타는 말풍선 위쪽에 맞춘다. 연속 글의 첫 줄만 위로 밀리지 않는다. 모바일 프리셋의 말풍선 안 시간 표시는 유지한다.
- 말풍선 글자 폭은 대상 GDI와 같은 장치 컨텍스트 오버로드로 잰다. 장치 컨텍스트 없는 MeasureText가 NoPadding을 무시해 남기던 오른쪽 여분 폭을 없앤다. 기본 말풍선 안 여백은 좌우 9px로 같다.
- 복숭아 내 말풍선은 사용자 요청에 따라 soft/text로 낮춘다. 컨트롤에는 accent/accentText를 유지한다.
