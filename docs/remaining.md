# 알려진 제한

- 게임 내부 구조가 업데이트되면 연결 구성요소 갱신이 필요할 수 있습니다.
- 캐릭터 '얼굴만' 표시는 연결 구성요소 0.1.1이 필요합니다. 구형 구성요소에서는 전체 그림으로 대체합니다.
- 게임 언어 리소스·파일 공유·본인 말풍선 수정은 연결 구성요소 0.1.4를 설치하고 게임을 재시작해야 적용됩니다.
- 메신저 송신의 본인 말풍선 표시는 사용자가 확인했습니다. 다른 참가자의 수신과 실제 상자 보상·선물은 별도 확인 항목입니다.
- 배율이 다른 실제 다중 모니터 사이 이동은 별도 수동 검증이 필요합니다.
- 대화는 일반 텍스트입니다. HTML 태그는 문자 그대로 표시하며 게임의 길이·문자 정책이 적용될 수 있습니다.
- 일부 밝은 테마의 보조 글자는 대비 4.5:1보다 낮습니다.
- Windows 인증서로 서명한 실행 파일은 아닙니다. 앱 업데이트 서명은 메타데이터와 실행 파일의 일치를 검증합니다.
