# 개발 안내

## D1. 빌드와 런타임

Windows x64, C# 5, .NET Framework 4.8을 사용합니다. build.ps1은 Framework의 csc.exe로 컴파일합니다.
NuGet 복원이나 .NET SDK 설치 없이 빌드합니다. 플러그인 컴파일에는 게임 설치 폴더의 관리형 DLL이 필요합니다.

## 구조

- src/Domain: 대화, 사람, 설정, 연결, 자동 기능, 업데이트 규칙
- src/Application: 사용 사례와 외부 입출력 포트
- src/Adapters: 파일 저장, 게임 연결, 설치, 업데이트, 메타데이터 검사
- src/App: WinForms 화면과 직접 그리는 대화 목록
- src/Shared: 앱·게임 플러그인의 교환 형식
- src/Plugin: BepInEx 5 연결 플러그인

검사 빌드는 계층을 별도 어셈블리로 컴파일하여 참조 방향을 확인합니다.
배포 빌드는 앱 코드·글꼴·연결 파일을 NyangTalk.exe 하나에 포함합니다.

## 화면 배율

DpiStartup은 앱 데이터 폴더의 display.runtime.config를 구성하고 PerMonitorV2 설정을 적용한 UI AppDomain을 시작합니다.
WinForms 초기화 전에 Framework 설정이 읽히므로 화면의 실제 DPI와 레이아웃 DPI가 일치합니다.
배포 실행 파일 옆에 config 파일을 따로 둘 필요가 없습니다.
저장한 창 크기는 96 DPI 기준 논리 크기이며 열 때 화면 배율로 변환합니다.
본문 기본 크기는 11pt이고 헤더 버튼·검색 표시·설정 행은 글꼴의 폭과 높이를 반영합니다.

## 업데이트와 릴리스

제품 버전은 src/App/AppHost.cs의 AppVersion에 있습니다.
첫 공개 버전은 0.1.0이며, 현재 수정판은 0.1.7입니다. 수정 배포에서는 버전과 CHANGELOG를 함께 갱신합니다.
연결 구성요소 0.1.1은 전체 캐릭터와 얼굴 전용 그림을 같은 단일 프레임 큐로 생성합니다.
게임 실행 중에는 구성요소를 교체하지 않으며, 구형 구성요소에서 얼굴 전용 표시를 선택하면 갱신 안내를 제공합니다.
메타데이터는 ECDSA P-256/SHA-256으로 서명하고 앱에 포함된 공개키로 검증합니다.
릴리스 개인키는 암호화하여 저장소 밖에 보관하며 배포하지 않습니다.
릴리스에는 실행 파일, update.json, 서명, 포함한 LGPL 구성요소의 소스 묶음을 첨부합니다.

## 게임 리소스 호환성

연결 구성요소 0.1.4는 게임 초기화 전 Addressables 카탈로그의 고정 형식 식별값을 보정합니다.
게임의 카탈로그는 원래 Unity 런타임의 문자열 해시를 저장하지만 Windows용 전체 라이브러리의 해시 구현은 다릅니다.
실제 Player.log의 Invalid header data 오류 뒤에 SelectedLocale is null 오류가 이어졌습니다.
알려진 magic 233015618·version 2·32바이트 헤더와 정확한 타입·필드 구조를 검증하고,
필드가 현재 런타임 해시를 그대로 사용하고 있을 때만 해당 정적 필드를 맞춥니다.
게임 카탈로그·어셈블리와 전역 문자열 해시는 바꾸지 않습니다. 알 수 없는 형식이나 다른 보정은 덮어쓰지 않고 로그와 연결 오류로 알립니다.
같은 유형의 상위 구성요소 문제는 [BepInEx 이슈](https://github.com/BepInEx/BepInEx/issues/1126)에 보고되어 있습니다.

## 교환 파일과 복구 알림

메신저는 실행 허가 파일을 임시 파일에서 교체합니다. 게임은 읽기·쓰기·삭제 공유를 허용한 스냅샷으로 읽고,
파일 교체 중 이름 변경이나 잠금 충돌은 제한된 짧은 재시도로 처리합니다.
읽기 실패 시 이전 허가를 다시 사용하지 않으며 해당 주기의 자동화를 중단합니다.
구성요소 오류는 작업별로 보관하고 그 작업이 성공했을 때 해제합니다. 다른 작업의 오류는 유지합니다.
화면도 정상 상태가 도착하면 이전 구성요소 경고만 제거하고, 새 오류가 재발하면 다시 표시합니다.

## 게임의 대화 표시

메신저 송신은 활성 씬의 메인 고양이 Vfx.CatSpeech.SendSpeech를 호출합니다.
네트워크 전송만 호출하면 본인 고양이의 말풍선은 갱신되지 않으므로 게임의 기본 처리 경로를 사용합니다.
대상은 계약의 메인 고양이 필드와 활성 씬·활성 오브젝트로 확인하고, 준비되지 않은 경우 명시적으로 거절합니다.
계약 버전 4는 이 메서드와 메인 고양이 식별자를 필수로 검사합니다. 일반 텍스트와 게임의 필터는 그대로 적용합니다.

## 전송 초안과 창 배치

전송 요청은 게임 응답을 기다리지 않고 입력창에서 비웁니다. 전송 대기·실패 원문은 기존 송신함에 보관합니다.
원문 복원은 자동 재전송하지 않으며, 새 초안이 있으면 메시지 아래에서 교체를 확인합니다. 확인 중 수정된 초안은 다시 확인합니다.
게임 필터 거절에는 내용 수정·원문 복원을 안내하고, 파일 쓰기 실패·결과 미확인과 구분합니다. 교환 스키마는 그대로 사용합니다.
바로가기는 사용자가 선택한 현재 사용자 시작 메뉴·바탕화면에만 만들고 고정 앱 경로와 EXE 아이콘을 사용합니다.
같은 이름으로 다른 프로그램을 가리키는 바로가기는 덮어쓰지 않으며 생성 실패는 위치별로 표시합니다.
설정창은 소유 창의 모니터 작업 영역에서 전체 크기 옆 배치, 최소 크기까지 조정한 옆 배치, 겹침이 적은 배치 순서로 결정합니다.
메신저 크기·위치와 Windows 배율은 변경하지 않습니다.
