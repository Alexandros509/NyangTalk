# 설치·복구 안내

## 처음 사용하기

게임을 종료하고 NyangTalk을 실행합니다. 게임 폴더를 선택하고 연결 구성요소를 설치한 뒤 게임을 실행합니다.
게임 로비에 들어가 앱 상단의 연결 상태를 확인합니다.
Enter는 전송, Shift+Enter는 줄바꿈입니다. 앱은 일반 텍스트를 표시합니다.

## 기존 설치가 있을 때

설치기가 충돌 파일을 알리면 안내에 따라 보관 작업을 먼저 진행합니다.
다른 플러그인을 덮어쓰지 않습니다. 보관된 파일과 설치 기록은 복구에 필요하므로 유지합니다.
보관·복원은 게임을 종료한 상태에서 진행합니다. 게임 파일 전체를 지우지 마세요.

## 게임 업데이트 이후 연결이 끊길 때

1. 게임과 앱을 종료했다가 다시 실행합니다.
2. 게임 폴더가 올바른지 확인합니다.
3. 앱의 연결 진단과 로그에서 호환성·플러그인 상태를 확인합니다.
4. 게임을 종료하고 연결 구성요소를 다시 설치합니다.
5. 계속 실패하면 앱 버전, 게임 버전, 개인 정보를 지운 진단 로그와 함께 문제를 알려 주세요.

## 수동 확인 항목

- 실제 로비에서 본인과 다른 참가자의 메시지 송수신
- 긴 메시지·줄바꿈에 대한 게임 채팅 정책
- 게임 재실행·로비 이동 후 연결 복구
- 선택형 상자 기능과 보상·선물 처리

이번 배포의 검증 범위는 verification.md에 기록합니다.
