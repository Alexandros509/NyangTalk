# 설치·복구 안내

## 처음 사용하기

게임을 종료하고 NyangTalk을 실행합니다. 게임 폴더를 선택하고 연결 구성요소를 설치한 뒤 게임을 실행합니다.
게임 로비에 들어가 앱 상단의 연결 상태를 확인합니다.
Enter는 전송, Shift+Enter는 줄바꿈입니다. 앱은 일반 텍스트를 표시합니다.

## 기존 설치가 있을 때

1. **게임과 기존 채팅 프로그램을 종료**합니다.
2. NyangTalk을 실행하고 **설정 → 연결**에서 게임 폴더를 확인합니다.
3. **이전 모드 옮기고 새로 설치**를 누르고 화면 안내에 따라 진행합니다.
4. 설치가 끝나면 게임을 실행하고 로비에서 연결 상태를 확인합니다.

기존 BepInEx와 모드는 게임 폴더 밖 앱 데이터의 parked-mods 폴더에 별도 보관합니다.
다른 BepInEx 모드도 함께 보관되어 비활성화됩니다.
원래 구성으로 돌아가려면 게임을 종료하고 **이전 모드 되돌리기**를 사용합니다.
보관 파일과 설치 기록은 복구에 필요하므로 유지합니다.
이미 NyangTalk만 설치되어 있으면 **연결 다시 설치**를 사용합니다.

0.1.3의 캐릭터 '얼굴만' 표시에는 연결 구성요소 0.1.1이 필요합니다.
기존 구성요소를 사용 중이면 게임을 종료한 뒤 설정의 연결에서 다시 설치하고 게임을 실행합니다.
갱신 전에도 채팅은 사용할 수 있으며 캐릭터는 기존 전체 그림으로 표시합니다.

## 게임 업데이트 이후 연결이 끊길 때

1. 게임과 앱을 종료했다가 다시 실행합니다.
2. 게임 폴더가 올바른지 확인합니다.
3. 앱의 연결 진단과 로그에서 호환성·플러그인 상태를 확인합니다.
4. 게임을 종료하고 연결 구성요소를 다시 설치합니다.
5. 계속 실패하면 앱 버전, 게임 버전, 개인 정보를 지운 진단 로그와 함께 문제를 알려 주세요.

## 수동 확인 항목

- 실제 로비에서 본인과 다른 참가자의 메시지 송수신
- 긴 메시지·줄바꿈에 대한 게임 채팅 정책
- 게임 재실행·로비 이동 후 연결 복구
- 선택형 상자 기능과 보상·선물 처리

이번 배포의 검증 범위는 verification.md에 기록합니다.
