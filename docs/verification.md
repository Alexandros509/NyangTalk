# 0.1.2 검증 기록

## 자동 검사

build.ps1로 도메인 규칙, 파일 교환, 실패·재전송, 설치·보관·복구, 업데이트 서명·롤백,
화면 배치·글꼴 변경, 말풍선 측정, 배포 파일·라이선스를 검사합니다.
최종 자동 검사는 221개 통과, 실패 0개입니다. 항목별 결과는 acceptance-status.md에 자동 기록됩니다.

DPI 설정 도메인 생성, 손상된 설정 재생성, 쓰기 오류 전파,
Shift+Enter의 실제 줄바꿈 보존과 일반 텍스트 태그 표시, 데모 식별도 검사합니다.

## 화면과 격리 검증

화면 배율 150%에서 네이티브 DPI와 WinForms DPI가 모두 144인 것을 확인했습니다.
Pretendard·Noto Sans KR·SUIT·맑은 고딕, 8·11·16pt, 논리 폭 300·510·820의 36개 조합과 설정 7개 페이지를 검사했습니다.
PerMonitorV2가 적용되었고 헤더 겹침·글자 높이 잘림·설정 백분율 폭 오류는 0건이었습니다.
격리된 데모에서 실제 두 줄 입력과 전송 후 두 줄 표시를 확인했습니다.
데모는 실제 게임에 전송하지 않습니다.

말풍선은 본문을 같은 기준으로 측정하고 그립니다. 복숭아 내 말풍선과 연결 알림은 부드러운 배경색을 사용합니다.
헤더 글자는 중간 저해상도 비트맵 확대 없이 화면에 직접 그립니다.

## 0.1.1 사이드바 회귀 검사

150% 배율에서 글꼴 4종·크기 3단계·필/아이콘 버튼·일반/짧은 창·오버레이의 72개 조합을 검사했습니다.
사이드바 제목·검색·로비·보관함·하단 이름과 상태가 겹치지 않고 글자 높이가 확보되는지 확인했습니다.
기본 창 크기 재적용, 작은 창의 세로 스크롤, 오버레이 종료 후 채팅 영역의 도킹 복구를 검사합니다.
설정 버튼은 모든 배치에서 헤더 최우측에 유지합니다. app.ico는 사용자 제공 원본으로 복원했습니다.

## 0.1.2 참여자 패널 회귀 검사

참여자 수·명단 조회 실패·마지막 확인 상태와 하단 안내는 실제 문장 폭과 줄 수로 높이를 계산합니다.
패널 폭과 도킹 기준은 DPI에 맞게 변환하고, 짧은 창에서는 안내와 닫기 버튼을 스크롤로 접근합니다.
150% 배율에서 한국어·영어·일본어, 글꼴 4종, 8·11·16pt, 3개 창 폭, 정상·조회 실패·마지막 확인 상태의 324개 조합을 검사해 오류 0건을 확인했습니다.
짧은 창의 안내·닫기 버튼 접근과 검색 영역 가림도 검사했습니다.

## 게임 연결 범위

2026-11-23 게임 시작 시 BepInEx 5.4.23.6과 NyangTalk 연결 플러그인 로드,
채팅 관련 훅 등록을 확인했습니다. Windows용 전체 시스템 라이브러리를 포함합니다.

이번 마무리 검수는 사용자 요청에 따라 실제 로비 조작 없이 진행했습니다.
실제 로비 송수신, 실제 상자 개봉·보상·선물은 이번 검증 범위에 포함하지 않았습니다.
파일 교환·전송·실패 처리는 격리된 게임 대역으로 확인했습니다.
