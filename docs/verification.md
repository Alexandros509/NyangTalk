# 0.1.4 검증 기록

## 자동 검사

build.ps1로 도메인 규칙, 파일 교환, 실패·재전송, 설치·보관·복구, 업데이트 서명·롤백,
화면 배치·글꼴 변경, 말풍선 측정, 배포 파일·라이선스를 검사합니다.
최종 자동 검사 결과는 acceptance-status.md에 자동 기록됩니다.
0.1.4 최종 자동 검사는 245개 통과, 실패 0개입니다.
보내기 버튼은 복숭아 테마에서 지정된 얼굴 바탕색 #DF557C와 글자색 #211417을 사용합니다.
둥근 모서리, 비활성 상태와 큰 글꼴의 한 줄 표시를 기존 테마·글꼴·창 폭 회귀 검사로 확인했습니다.

DPI 설정 도메인 생성, 손상된 설정 재생성, 쓰기 오류 전파,
Shift+Enter의 실제 줄바꿈 보존과 일반 텍스트 태그 표시, 데모 식별도 검사합니다.

## 화면과 격리 검증

화면 배율 150%에서 네이티브 DPI와 WinForms DPI가 모두 144인 것을 확인했습니다.
Pretendard·Noto Sans KR·SUIT·맑은 고딕, 8·11·16pt, 논리 폭 300·510·820의 36개 조합과 설정 7개 페이지를 검사했습니다.
PerMonitorV2가 적용되었고 헤더 겹침·글자 높이 잘림·설정 백분율 폭 오류는 0건이었습니다.
격리된 데모에서 실제 두 줄 입력과 전송 후 두 줄 표시를 확인했습니다.
데모는 실제 게임에 전송하지 않습니다.

말풍선은 본문을 같은 기준으로 측정하고 그립니다. 복숭아 내 말풍선과 연결 알림은 부드러운 배경색을 사용합니다.
헤더 글자는 중간 저해상도 비트맵 확대 없이 화면에 직접 그립니다.

## 0.1.1 사이드바 회귀 검사

150% 배율에서 글꼴 4종·크기 3단계·필/아이콘 버튼·일반/짧은 창·오버레이의 72개 조합을 검사했습니다.
사이드바 제목·검색·로비·보관함·하단 이름과 상태가 겹치지 않고 글자 높이가 확보되는지 확인했습니다.
기본 창 크기 재적용, 작은 창의 세로 스크롤, 오버레이 종료 후 채팅 영역의 도킹 복구를 검사합니다.
설정 버튼은 모든 배치에서 헤더 최우측에 유지합니다. app.ico는 사용자 제공 원본으로 복원했습니다.

## 0.1.2 참여자 패널 회귀 검사

참여자 수·명단 조회 실패·마지막 확인 상태와 하단 안내는 실제 문장 폭과 줄 수로 높이를 계산합니다.
패널 폭과 도킹 기준은 DPI에 맞게 변환하고, 짧은 창에서는 안내와 닫기 버튼을 스크롤로 접근합니다.
150% 배율에서 한국어·영어·일본어, 글꼴 4종, 8·11·16pt, 3개 창 폭, 정상·조회 실패·마지막 확인 상태의 324개 조합을 검사해 오류 0건을 확인했습니다.
짧은 창의 안내·닫기 버튼 접근과 검색 영역 가림도 검사했습니다.

## 0.1.3 설정 미리보기 회귀 검사

미리보기에 전용 이모티콘·캐릭터 예시 그림을 연결하고, 헤더 버튼 예시를 추가했습니다.
22개 설정의 58개 선택값이 활성 조건에서 서로 다른 결과를 표시하는지 픽셀 비교로 확인했습니다.
글꼴 4종·8/11/16pt·한국어/영어/일본어·설정 창 폭 2종의 72개 조합에서
432개 대화 미리보기의 높이와 설정 분류의 접근성을 검사해 오류 0건을 확인했습니다.
실행 화면에서도 필/아이콘 전환과 캐릭터 예시의 변경을 확인했습니다.

작업 표시줄 알림 예시가 일반 폴링에 지워지지 않고 실제 읽지 않은 수로 복구되는지,
투명도 슬라이더의 임시 값이 타이머와 설정 창 닫기에 맞게 유지·취소되는지 검사했습니다.
컴팩트 표시에서 크기가 고정되는 이유와 구형 연결 구성요소의 얼굴 그림 제한을 안내합니다.
얼굴 전용 그림은 연결 구성요소 0.1.1부터 별도 파일로 제공합니다.
구형 구성요소에서는 전체 그림으로 대체하며 채팅 연결은 유지합니다.

## 0.1.4 실행 경로 검사

실제 설정에서 내 상자 자동 열기는 켜져 있지만, 로비가 없는 게임 상태에서 허가 파일이 갱신되지 않는 것을 확인했습니다.
내 상자는 로비 유무와 무관하게 현재 게임 세션으로 허가하고, 선물은 로비와 별도 동의를 요구하도록 수정했습니다.
설정·세션 변경은 즉시 반영하며 연결 끊김·준비 안 됨·미지원 상태에서는 허가를 취소합니다.
실제 게임의 CanGetChest가 준비 상태와 구매 가능 상태를 함께 검사하므로 포인트 부족을 먼저 표시하도록 순서를 수정했습니다.

게임 로그에서는 카탈로그 Invalid header data 오류 다음에 SelectedLocale is null 오류가 이어졌습니다.
게임 원래 런타임의 카탈로그 식별값 233015618과 Windows용 전체 라이브러리가 계산하는 값 -1444555298의 차이를 확인했습니다.
카탈로그 형식·타입·필드와 현재 런타임 값을 확인한 뒤 해당 정적 필드만 보정합니다.
테스트는 알려진 불일치, 기존 호환, 다른 보정, 잘린/알 수 없는 헤더, 변경된 필드, 파일 불변과 오류 전파를 포함합니다.
새 연결 구성요소를 적용한 게임 재시작에서 카탈로그 보정 Applied, 헤더 오류·언어 선택 오류·기타 예외 0건을 확인했습니다.
로비가 없는 상태에서도 실행 허가가 갱신되고 게임이 상자 준비 대기를 보고하는 것을 확인했습니다.
Esc로 화면 제어가 중단되어 게임 설정창의 육안 확인은 남아 있습니다.
플러그인 참조 검사는 Doorstop이 선택한 전체 라이브러리, 로더 라이브러리, 게임 모듈 순서로 확인합니다.

실제 permit.json 공유 잠금 충돌도 확인했습니다. 교체 시 읽기 공유와 짧은 재시도, 작업별 복구 상태와 화면 경고 해제를 수정했습니다.
Windows에서 기존 공유 방식의 실패를 재현하고, 400회 교체·800회 읽기에서 완전한 스냅샷만 읽는지 검사합니다.
지속 잠금·크기 초과는 오류로 전파하며 성공한 다른 작업이 실패를 지우지 않는지 검사합니다.

송신 경로는 게임의 네트워크 함수와 기본 대화 함수를 비교했습니다.
네트워크 함수만 호출하면 본인 말풍선 갱신이 빠지므로 활성 메인 고양이의 기본 대화 함수로 연결했습니다.
실제 계약 해석 코드를 격리된 대역에 연결해 네트워크 전용 경로와 본인 표시가 포함된 경로의 차이,
필터 차단 시 네트워크·화면 양쪽에 부작용이 없는지 확인합니다.
다른 참가자 화면의 수신 여부는 별도 실측 항목입니다.
최종 구성요소 0.1.4 적용 후 사용자가 메신저의 보내기 버튼으로 보낸 글이 게임 본인 말풍선에 표시되는 것을 확인했습니다.
재시작 후 구성요소 오류, chest failed, 카탈로그 헤더 오류와 언어 선택 오류는 0건이었습니다.
상자 기능은 새 허가를 읽으며 준비 대기를 보고했습니다. 실제 상자 보상 수령은 별도 확인 항목입니다.

## 게임 연결 범위

2026-11-23 게임 시작 시 BepInEx 5.4.23.6과 NyangTalk 연결 플러그인 로드,
채팅 관련 훅 등록을 확인했습니다. Windows용 전체 시스템 라이브러리를 포함합니다.

자동 검수에서는 실제 로비 조작이나 메시지 전송을 수행하지 않았습니다.
사용자가 직접 보낸 메시지의 본인 말풍선 표시는 확인했으며, 다른 참가자의 수신과 실제 상자 개봉·보상·선물은 별도 확인 항목입니다.
파일 교환·전송·실패 처리는 격리된 게임 대역으로 확인했습니다.
